# 🎮 Hangman Game

A classic word-guessing game with **web** and **Python** versions.

## 🚀 Quick Start

**Web Version:**
- Open `index.html` in your browser
- Click letters to guess
- No installation needed

**Python Version:**
```bash
python main.py
```

## ✨ Features

- 🎨 Modern dark-themed web UI
- 📊 Scoreboard (wins/losses)
- 💡 Hints for each word
- 📱 Responsive design
- ⚡ Zero dependencies
- 🐍 Pure Python CLI version


## 🎯 How to Play

1. Guess a letter
2. 6 incorrect guesses allowed
3. Reveal all letters to win
4. Click Restart/Play Again for next round

## 🔧 Customize

Add words in `script.js` (web) or `main.py` (Python):
```javascript
{ value: "word", hint: "Description" }
```
